The purpose of this project is to create a binary which can search Hong Kong's
company search API to make it a bit easier.

The dataset is called "Registered Office Address of Live Local Companies and Principal Place of Business of Registered Non-Hong Kong Companies"
The dataset is provided by the Companies Registry and is updated daily.

Link to this API on HK's data registry: https://data.gov.hk/en-data/dataset/hk-cr-crdata-list-addr/resource/1214e348-7069-440e-8144-6483fc944090

The data dictionary is in the data_dictionary_RO_PPB_en-2.docx file.
